# Lens library

A seed list, not a closed set. Reach beyond it whenever the subject calls for it. Entries are grouped by mechanism because lenses are chosen by what they claim about a process, not by their topic. Each entry gives the claim, a way to use it, and where it breaks. Details come from memory; verify dates, titles and wording with a search when tools allow, and hedge when they do not.

Before using any lens, check the user's seen-list. Entries marked (spoilers) must not be described beyond formal facts unless the user has seen or read the work.
