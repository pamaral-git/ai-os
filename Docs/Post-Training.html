Three questions, and they are not the same question. DPO asks which of two answers you would rather have written. GRPO asks whether a program, not a teacher, can tell a better sample from a worse one. CPT asks what it costs to make a small model less surprised by a library it has not read, without scraping away the skills you already paid for.

The machine is the constraint that makes the philosophy concrete. Twenty-four gigabytes is one pool, shared by the weights, the optimizer, the activations, and macOS. A preference pair is two sequences. A GRPO step is K sequences. A full fine-tune stores the weights again as gradients and again as Adam’s memory. The memory page is where those sentences become a number you can reject.

How to use a question

The blocks with an ember rule are closed on purpose. Write a sentence before you uncover the claim. The claim is not a grade. If you could have said it, you already know the page. If you could not, the miss is the part worth keeping.

Treat every gigabyte on the memory page as a hypothesis, about thirty percent either way, until you measure peak memory on the metal. Log one paragraph per run, dated in ISO 8601 with the offset +01:00.

How to read a symbol

You do not need to have enjoyed school algebra. You need a pronunciation.

  • A capital letter is a whole object. W is the weights. L is the loss, which is just the penalty.
  • P(a | b) is "the probability of a, once b is known." The bar is the word given.
  • A Greek letter is a knob you choose. β is how tightly you hold the old model. λ is a mix. ε is a speck that stops a division from exploding.
  • Σ means add these up. ‖W‖ is the length of W as an arrow: how big the change is, ignoring direction.
  • log gets large and negative when a probability gets tiny. Minus log is therefore a penalty for being surprised.
  • σ folds any number into a value between 0 and 1. σ(0) is one half. You can use it before you love it.
The only fact about σ you will need
σ(z) = 1 / (1 + e^(−z))
σ(0) = 0.5
large positive z → near 1
large negative z → near 0

Start with the budget, not the loss.
