Pipeline

Four stages, one careful handoff

01

Prepare pages

Ingest photos, PDFs, or EPUBs. Natural sort, EXIF rotation fix, and page_0001.png naming.

02

OCR with layout

OpenAI-compatible Docker endpoint, GGUF, MLX, or RapidOCR. One page per request, cached and resumable.

03

Build Markdown

Trailing-space line breaks, &nbsp; indents, escaped punctuation, and # titles.

04

EPUB or audiobook

Calibre compiles the EPUB with a TOC. Prose mode adds chapter detection, TTS, and .m4b output.

Design guarantees

  • Indents survive via &nbsp; instead of collapsing in Markdown
  • Machine-readable # Title headings build the EPUB TOC
  • Poetry is never re-flowed or de-hyphenated; prose mode still is
  • Header/footer stripping checks page edges only so refrains stay intact
  • Works with any OpenAI-compatible vision endpoint in Docker
  • 5-page sample runs, --resume recovery, and editable JSON cache

Quick start

Run five pages first

Sample & full run 
pip install pymupdf pillow tqdm       # plus Calibre: sudo apt install calibre

python book_pipeline.py ~/poetry_book/images \
  --mode poetry --pages 1-5 \
  --ocr openai --api-base http://localhost:11434/v1 --ocr-model qwen2.5vl:7b \
  --title "My Poetry Book" --author "Some Poet" --output-dir ./mybook

# looks right? run the whole book (finished pages are reused)
python book_pipeline.py ~/poetry_book/images --mode poetry --resume \
  --ocr openai --api-base http://localhost:11434/v1 --ocr-model qwen2.5vl:7b \
  --title "My Poetry Book" --author "Some Poet" --output-dir ./mybook

What you get

3. Markdown format

          

            

              
                

                  Feature
                  Meaning
                  Markdown
                  Result
                

              
              
                
Poem titleCentered/bold# Title NameHeading + page break + TOC

                
Line breakEnd of printed lineTwo trailing spacesHard <br>

                
Stanza breakVertical gapOne empty lineNew paragraph

                
IndentIndented / turnover&nbsp; relative to left edgeVisible indent

                
Special chars*, _, <, &, 1., -EscapedPrinted verbatim

              
            

          


          

            

              Markdown example
              
            

            
# The Silent Horizon

The evening falls across the graying stone,  
&nbsp;&nbsp;The shadows lengthen as the wind cries out,  
And standing on the quiet crest alone,  
&nbsp;&nbsp;The traveler abandons every doubt.

A single leaf deserts the frozen bough,  
&nbsp;&nbsp;&nbsp;&nbsp;To find its final rest upon the stream.

          

          

            Poems crossing a page without # are treated as continuations (default --page-join stanza; use line if a stanza splits mid-page) and flagged in review_report.txt. Digit-only first/last lines are stripped unless --keep-page-numbers is passed.
          

        


        

          
4. Markdown to EPUB with Calibre

          

            

              Calibre command
              
            

            
ebook-convert mybook/My_Poetry_Book.md mybook/My_Poetry_Book.epub \
  --formatting-type markdown --input-encoding utf-8 \
  --title "My Poetry Book" --authors "Some Poet" --language en \
  --level1-toc "//h:h1" --page-breaks-before "//h:h1" --chapter-mark none \
  --extra-css mybook/poetry.css --no-default-epub-cover

          

          

            --level1-toc "//h:h1" builds the TOC from # titles, --page-breaks-before starts each poem on a fresh page, and poetry.css keeps stanzas together.

6. Troubleshooting

          

            

              
                

                  Problem
                  Fix
                

              
              
                
Lines mergedInspect .md first, then rebuild with Calibre

                
Indentation missingUse a larger vision model or raise --indent-scale

                
Connection refusedVerify --api-base URL and port

                
Model adds preambleSet temperature to 0 and use the exact system prompt

                
ebook-convert not foundInstall Calibre or pass --no-epub

                
Whole book re-OCR’dPass --resume

                
Piper silenceEnsure .onnx and .onnx.json sit beside each other

Prose mode

      
Chapters & audiobooks


      

        

          Prose commands
          
        

        
python book_pipeline.py book.epub --mode prose --ocr onnx --tts piper --piper-model en_US-lessac-medium.onnx --output-dir ./mybook
# text and chapters only, quicker
python book_pipeline.py book.pdf --mode prose --no-audio --resume --jobs 4

      


      
    
        
  • EPUB/MOBI/AZW3 files convert to PDF via Calibre; chapters come from the PDF outline or heading detection (Chapter One, CHAPTER 1:, Part I, Prologue, Appendix A).
    • 
        
  • Applies de-hyphenation, ligature fixes, paragraph re-flow, and edge page-number/header removal.
    • 
        
  • Splits at ~850 characters on sentence boundaries for Piper or pyttsx3 TTS, then joins with ffmpeg into an .m4b audiobook with chapter marks.
    •
